# Events website requirements

Players use this site to decide what to play and join the TheySix Events server. A first-time player needs the address, edition-specific instructions and the steps to enter a game.

- Keep the join information consistent across the home, server and how-to-play pages.
- Publish game names and commands, arena formats, rules, rank information and voting instructions from the shared data files.
- Make the server address and instructions available even when a status check fails. Distinguish an unavailable reading from a confirmed player count.

## Acceptance check

From a phone, find a game, read its instructions and locate the server address. Compare the displayed game command and arena format with their records in `src/data`.
