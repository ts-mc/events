# Events design system

Use [globals.css](src/app/globals.css) for dark surfaces, borders and interaction states. The base is #020202, elevated areas use #23212c, primary text is #f1fec8, and the brand accent is #99e1d9. Retain the configured category colors and rank gradients in roster displays.

Give game names and joining instructions priority over metadata. Keep addresses and slash commands selectable and readable as literal strings. Use the same spelling and capitalization in cards and detail sections.

Reuse the existing navigation, logo and icon treatment. Pair status colors with text, keep actions reachable by keyboard and check the join controls and roster at phone width.
